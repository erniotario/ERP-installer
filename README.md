# ERP — gestion commerciale

Installateurs d'**ERP**, le logiciel de gestion commerciale de **SHEMA BUSINESSES**
(Yaoundé) : caisse, stock et dépôts, achats, créances, comptabilité, personnel et paie —
sur Windows et Android.

Les versions sont dans **[Releases](../../releases)** :

- `ERP_Setup.exe` — installateur Windows ;
- `ERP-X.Y.Z.apk` — application Android ;
- le guide de l'utilisateur en PDF.

**Installez la même version sur le PC et sur les téléphones** qui se synchronisent
ensemble. ERP annonce lui-même une nouvelle version au pied du menu ; rien ne s'installe
tout seul.

ERP s'essaie gratuitement pendant 30 jours ; ensuite, une licence est nécessaire.
Contact : SHEMA BUSINESSES.

Ce dépôt ne contient que les versions publiées, pas le code.
